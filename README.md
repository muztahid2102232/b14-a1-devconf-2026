# DevConf 2026

A modern and responsive developer conference landing page built with HTML5 and CSS3. The website is designed to promote DevConf 2026 and provides visitors with information about the conference, featured speakers, ticket pricing, benefits of attending, and other event details through a clean and professional interface.

## ✨ Features

The DevConf 2026 website includes the following sections:

### Navigation Bar

- Clean and simple navigation menu
- Navigation links for Speakers, Schedule, Tracks, Venue, and Blog
- Prominent "Register Now" call-to-action button

### Hero Section

- Eye-catching conference introduction
- DevConf 2026 event branding
- Short overview of the conference
- "Register Now" call-to-action button
- Modern and responsive hero design

### Meet the Speakers

- Dedicated speaker showcase section
- Speaker profile cards
- Speaker names and professional roles
- Different conference topics and categories

### Pricing Plans

The website provides three different ticket plans:

- **Standard** — $399 per person
- **Pro** — $749 per person
- **Team** — $5,999 for up to 10 people

Each plan includes different conference benefits and access options.

### Stay Updated about DevConf 2026

- Get the latest conference news, speaker announcements, workshop updates, and exclusive early-bird discounts delivered straight to your inbox.
- stay connected by subscribing with your email and get important info quickly.

### Footer

- Conference branding
- Social media icons
- Clean and professional footer design

## 🚀 Local Development Setup

No installation or build process is required to run this project locally.

### Clone the Repository
`git clone https://github.com/muztahid2102232/b14-a1-devconf-2026.git`

### Navigate to the Project Directory <br>

`cd b14-a1-devconf-2026`

### Run the Project <br>
Simply open the `index.html` file in your web browser.
For a better development experience, you can also use the Live Server extension in Visual Studio Code.
